# 关键修改

## 2026-10-08（双击标签打开目录）
- 左键双击文件夹标签时按鼠标命中确定目录，通过 Shell 的 explore 动作在资源管理器中打开，支持中文及空格路径。
- “其它”和标签空白区域无操作；Shell 无法打开目录时使用中英错误提示。单击切换和右键文件选择保持原有行为。

## 2026-10-07（发布标签修正）
- 根据用户实际标签 `releases/v1.1.1` 修正发布地址；生成脚本默认沿用 `releases/v<版本>`，支持显式 `-Tag`。
- 下载 URL 保留标签路径，附件名按 URI 编码；同步更新官方列表条目、PR 草稿和清单，不重打已发布 ZIP。

## 2026-10-07（1.1.1 发布准备）
- 升级到 1.1.1，纳入活动文件目录初始化修改，避免与既有 1.1.0 包混淆。
- 二进制 ZIP 改为根目录 DLL，核对 FileVersion/ProductVersion；源码包包含换行规则，排除 Python 缓存。
- 新增发布准备脚本，生成 SHA-256、官方列表 JSON、发布说明、清单和 PR 草稿；提供上传后公开下载校验。
- 新增真实插件管理器与官方 validator 包装脚本，隔离验证安装、移除、升级、配置保留及 schema/版本/哈希/名称唯一性。
- 修复鼠标辅助函数参数覆盖；插件管理器采用原生方向键，并在副本中强制多实例，保证重启隔离。
- 发布仅提供 x64，最低支持基线保守设为已验证的 Notepad++ 8.9.8.1；未公开发布或提交 PR。

## 2026-10-07（1.1.0）
- 新增 `docs/official-plugin-list.md`，汇总官方插件列表收录要求、提交步骤和项目待补事项，便于正式发布时查阅。
- 添加文件夹的默认路径改为当前活动文件的父目录；实时读取宿主 buffer，避免被面板选中标签或缓存文档列表影响。
- 使用 IFileDialog::SetFolder 覆盖系统记忆位置，确保切换文件后默认目录随之更新；未保存文档或目录无法定位时沿用系统默认位置。

## 2026-10-05（1.1.0）
- 语言设置从停靠面板移到“插件 → folderpad++ → Settings... | 设置…”独立窗口；确定后保存并刷新，取消和关闭不修改配置。
- 移除面板语言控件，收回其占用空间；设置命令追加到菜单末尾，保持原有命令索引与停靠 ID 稳定。
- 右键标签通过命中检测确定目录，调用原生文件选择窗口；使用 SetFolder 覆盖系统记忆位置，支持多选后逐个交由 NPPM_DOOPEN 打开。
- “其它”使用系统默认目录，空白区域不处理；支持键盘上下文菜单；目录不可访问时明确报错，不静默转到其它目录。
- 沿用已有 INI 的 Language 字段；版本升级为 1.1.0。

## 2026-10-05（1.0.1）
- 修复缩放后 TabControl 背景遮盖列表：调整 Z 顺序、同级裁剪和重绘，多行标签切换后也重新布局。
- 增加 PowerShell 版本升级脚本，支持默认 patch、minor/major、指定版本、current、可选构建打包，无需 npm。
- 将版本集中到 src/version.h，新增 DLL VERSIONINFO；关于窗口与打包使用同一来源。
- 打包核对 DLL 版本，并使用独立打包目录，防止旧产物混入。
- 新增四种宽度的遮挡回归及 17 项版本 CLI 检查；语言入口暂不迁移。

## 2026-10-04
- 选择 C++ / Win32 原生插件接口，避免额外运行时依赖，兼容宿主停靠机制。
- 将路径归属从 UI 分离，保证目录边界和嵌套目录规则可独立验证。
- 使用官方插件模板接口头文件，保留原始许可与来源信息。
- 完成左侧停靠面板、文件夹标签和计数、相对路径列表、点击/键盘激活、目录添加/移除和中英语言切换。
- 使用 buffer ID 枚举并去重双视图文档，合并刷新响应打开、关闭、激活、保存和重命名事件。
- 排除隐藏视图的占位文档，修正“其它”计数；保留宿主整体隐藏时的测试能力。
- 以 UTF-16 INI 和同目录临时文件替换保存配置，支持中文路径和中断保护。
- 增加便携工具链、构建、安装、打包脚本，以及路径单元测试与隔离的真实宿主测试。
- 补齐 GPL-3.0-or-later 许可、SDK 来源、使用说明、中文问题记录和交接计划。
