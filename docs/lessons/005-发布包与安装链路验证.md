# 发布包与安装链路验证

- 宿主内功能测试和插件管理器安装测试覆盖不同环节；DLL 可加载并不代表 ZIP 布局、版本、下载哈希都正确。
- 提交准备应使用实际发布 ZIP：根目录 DLL、FileVersion、SHA-256、架构及元数据必须一起核对。
- 发布前可用 loopback HTTP 验证真实下载和更新链路，上传后仍须核对公网下载字节，不能把本地成功当作公网已验证。
- UI 自动化应等待窗口、菜单、标签和按钮状态；原生键盘通知比直接设置选中索引更接近实际操作。
- 修改测试辅助函数后，应重新检查受影响的已有场景；变量同名覆盖可能使测试表面通过却执行了错误动作。
- 固定最终二进制包后再生成提交条目；源码包可记录验证过程，但最终源码哈希应放在包外，避免自引用。
