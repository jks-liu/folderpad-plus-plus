# 以宿主文档为唯一数据源

- “打开文件夹”在本插件中表示添加分组，不能沿用文件树插件的递归扫描方案。
- 使用 buffer ID 作为文档身份，从两个视图枚举宿主文档并去重；路径仅用于显示和归属。
- 目录匹配必须检查分隔符边界，避免 `work-other` 被归入 `work`；嵌套目录按最长匹配选择。
- 路径比较使用 Windows ordinal 大小写不敏感规则；不能依赖 C/C++ 当前区域设置的小写转换。
- 文件另存为后 buffer 身份可能不变但路径改变，应重新查询路径并分组。
- 通知回调中合并刷新，在宿主完成当前事件后更新控件，避免关闭过程读取过渡状态。
- 通过词法规范化处理斜杠、点路径与扩展前缀，不做网络探测、目录枚举或链接解析。
- 配置写入采用同目录临时文件加原子替换，避免一次写入中断损坏原配置。
