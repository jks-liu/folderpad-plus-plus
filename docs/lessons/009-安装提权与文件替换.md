# 安装提权与文件替换

- 先校验 DLL 与宿主位数并检查目标进程。可写目录直接安装，受保护路径由 Windows UAC 确认后重试。
- 安装时在目标目录暂存新 DLL，再移动或替换文件。升级时将上一个 DLL 保存为 `.bak`，出现占用时提示关闭对应实例，并清理暂存文件。 [Microsoft File.Replace 文档](https://learn.microsoft.com/dotnet/api/system.io.file.replace)
- 测试可对隔离目录设置写入拒绝，用替身记录实际 `RunAs` 调用参数并模拟 UAC 取消。可写目录、正在运行的宿主和文件占用则可以通过真实安装与文件锁验证。
