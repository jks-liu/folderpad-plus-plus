# 双击标签与资源管理器验证

## 问题与处理
- 当前选中标签可能与双击目标不同。处理 WM_LBUTTONDBLCLK 时通过消息坐标执行 TabCtrl_HitTest，只打开命中的真实文件夹；“其它”和空白区域直接返回。
- 中文与空格路径不宜拼接为 shell 命令。使用 ShellExecuteExW 的 explore 动作，将 UTF-16 目录作为独立参数；关闭 Shell 默认错误界面，失败时显示插件中英提示。
- 实际 Explorer 打开动作跨进程且异步。测试使用 Shell.Application 查询完整目录位置，等待目标出现；目录位于本次隔离测试创建的唯一路径下，检查后关闭测试窗口。
- 新增辅助函数时曾误将 Remote.close 缩进到普通函数内，导致首次回归收尾异常。恢复类方法，并以 finally 保证释放远程内存、关闭隔离宿主；已关闭失败测试残留的宿主。

16 项路径检查、26 项真实宿主检查通过。新增三项覆盖父目录、嵌套目录、中文与空格路径，以及“其它”/空白无操作和单击切换；原右键打开文件场景继续通过。报告：`build/smoke-20261008-230029/result.json`。
