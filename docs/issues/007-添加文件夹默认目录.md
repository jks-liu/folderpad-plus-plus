# 添加文件夹默认目录

## 问题
添加文件夹窗口未指定初始目录，会使用 Shell 记忆的位置，可能与当前编辑文件无关。面板选中的标签也不一定对应当前活动文件。

## 处理
- 每次打开窗口时通过 NPPM_GETCURRENTBUFFERID 和 NPPM_GETFULLPATHFROMBUFFERID 获取活动文档路径，取绝对路径的父目录。
- 使用 SetFolder 强制初始位置，避免 SetDefaultFolder 被历史位置覆盖。
- 未保存文档不具有绝对路径，不指定目录；Shell 无法定位时保留系统默认行为，仍允许手动选取。
- 真实宿主依次激活父目录文件和嵌套目录文件，直接确认选择窗口，验证重复目录去重及新增目录的持久化路径。
