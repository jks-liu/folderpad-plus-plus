# 右键关闭命中与原生提示

隔离宿主测试最初点击到相邻行。诊断发现测试进程从列表取得原生客户区坐标，但 Python 线程与宿主 DPI 感知不同。向宿主投递鼠标消息时，坐标又按 125% 缩放。测试现以目标窗口的 DPI 感知上下文投递鼠标消息，并在随后恢复原上下文。

文件列表响应原生 `NM_RCLICK` 通知，用 `ptAction` 重新命中整行。命中有效文件行后投递 buffer ID，处理时再查询宿主位置并核对活动文档。 [Microsoft 列表控件右键通知](https://learn.microsoft.com/en-us/windows/win32/controls/nm-rclick-list-view)

等右键处理返回后调用 Notepad++ 的文件关闭命令。宿主负责处理未保存确认和双视图副本。提示窗口运行期间屏蔽重入的关闭请求，避免嵌套打开关闭提示。 [Notepad++ 文件关闭流程](https://github.com/notepad-plus-plus/notepad-plus-plus/blob/v8.9.8/PowerEditor/src/NppIO.cpp#L1127)
