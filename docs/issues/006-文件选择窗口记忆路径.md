# 文件选择窗口记忆路径与自动化

## 问题
Windows 文件选择窗口会记忆上次目录。标签右键的语义要求每次从所点目录开始，不能被历史目录覆盖。原先自动化测试也曾默认“添加文件夹”始终选中 Documents，新功能使用原生窗口后改变了该历史位置，导致旧测试假设失效。

## 处理
- 每次右键先命中检测标签，将目录复制到局部字符串；即使当前选中的标签不同或宿主后来刷新，起始目录不变。
- 调用 IFileDialog::SetFolder，而不是只设置一个可被历史记录覆盖的默认目录。
- 目录不可访问时退出并提示；“其它”明确不指定目录。
- 测试依次右键父目录、嵌套目录，仅输入相对文件名，核对宿主最终打开的完整路径，验证第二次打开没有沿用第一次的目录。
- 自动化通过 WM_CHAR 输入文件名，让 Shell 收到编辑通知；单纯 WM_SETTEXT 不一定更新 Shell 内部的选定文件名。
- 原生目录选择的旧测试不再假定其初始目录固定为 Documents，点击验证使用不受嵌套标签影响的直接子文件。
