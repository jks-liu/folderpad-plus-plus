# 普通标签无法自动发布

## 原因

原发布脚本通过 `git cat-file -t` 要求对象类型必须为 `tag`，只接受 annotated tag。普通 lightweight tag 直接指向 commit，因此会在校验阶段失败，无法进入构建发布流程。

## 解决与验证

按用户要求取消对象类型检查，统一用 `git rev-parse --verify refs/tags/<名称>^{commit}` 解析标签对应提交，同时兼容轻量和附注标签。显式限定 `refs/tags/`，避免同名分支被误认为标签；名称、版本、提交和发布说明校验保持有效。

隔离测试覆盖普通标签成功、附注标签成功、标签对象 SHA 解析、同名分支不能替代缺失标签，以及指向 tree 的标签被拒绝；不修改真实仓库 tag。
