# 构建环境与脚本参数

## 问题
初始仓库只有说明文档，PATH 中没有 CMake、MSVC 或 GCC。PowerShell 将未引用的 `-Wl,--no-insert-timestamp` 中逗号视为语法，导致构建脚本解析失败。

## 解决
在 `.cache/toolchain` 使用固定版本 llvm-mingw 20260922，直接编译 Win32 资源和 C++ DLL；不安装全局工具链。将含逗号的链接参数用单引号包裹，保持单个参数。静态链接 C++ 支持库，发布 DLL 仅依赖 Windows 系统库。

## 验证
x64 DLL 编译成功；检查六个插件导出函数齐全。16 项路径归属测试通过。`tools/setup-toolchain.ps1` 支持用户指定 HTTP 代理；本次编译器下载在代理信息提供前已经完成，后续代理连接曾超时，无需重新下载。
