# 安装目录权限

向 `C:\Program Files\Notepad++\plugins\folderpad++` 创建目录时系统返回 Access denied，当前执行环境不能提权。

处理：不修改 ACL、不关闭用户编辑器，提供安装包和安装脚本。用户可通过管理员 PowerShell 运行 `tools/install.ps1`，或用资源管理器复制安装包中的 `plugins/folderpad++` 到 Notepad++ 目录并确认系统权限提示。

首次安装下次启动生效；更新已有 DLL 时要求先关闭宿主并保留 `.bak` 备份。安装脚本核对 PE 架构，防止位数不匹配。

## 2026-11-25 更新

- 现在可双击二进制包中的 `Install.cmd`，也可直接调用 `tools/install.ps1`。写入受限时，脚本使用 Windows 的 `RunAs` 动词请求 UAC，同步等待子进程结果，并在取消提权后显示明确提示。 [Microsoft Start-Process 文档](https://learn.microsoft.com/powershell/module/microsoft.powershell.management/start-process?view=powershell-5.1)
- 提权子进程的初始目录可能与调用方不同。启动前解析脚本、DLL 和目标目录的绝对路径，分别加引号，保留空格、中文及特殊字符。
- 安装错误通过标准错误输出单行消息，避免 Windows PowerShell 的错误视图按控制台宽度拆断提示文本。
