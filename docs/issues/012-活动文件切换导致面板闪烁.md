# 活动文件切换导致面板闪烁

点击文件触发 `NPPN_BUFFERACTIVATED`。原处理重新枚举文档路径、删除并重建文件夹标签及文件列表，再擦除重绘整个面板。长列表的回收和重插放大了闪烁，也会重置滚动位置。

活动缓冲区通知合并后，先比较可见视图的 buffer ID 顺序。同一文件夹内的文件集合和顺序相同时，仅同步文件行的选中与焦点状态。活动文档跨文件夹时切换标签并加载该页。打开、关闭、保存、重命名等操作继续读取宿主文档状态，保持列表、路径和计数正确。

回归测试在 49 行列表中滚动后点击可见行，核对激活目标、滚动位置、行状态和标签及列表项的自定义参数。自定义参数随控件项删除而消失，可用于检出整表重建。通过 `LVM_GETITEMSTATE` 读取选中与焦点位。
