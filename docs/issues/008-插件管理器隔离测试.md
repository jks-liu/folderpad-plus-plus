# 插件管理器隔离测试

## 问题
- GUP 重启宿主不带启动时的 `-multiInst`，若副本配置仍为单实例，重启不能留在测试目录。
- 插件管理器菜单受宿主语言影响，窗口创建后菜单也未必立即就绪。
- 原鼠标辅助函数将矩形右边界赋给同名 `right` 参数，把左键误发为右键；插件管理器标签切换因此无法验证。
- 插件管理器标签的鼠标行为还依赖宿主自定义 TabBar；只发送鼠标消息并不总能切换。

## 解决
- 测试副本先写入多实例配置 `multiInst setting=2`，禁用会话恢复和自动更新；所有操作通过完整可执行文件路径限定到该副本。
- 使用官方命令 ID 48015，等待菜单就绪，不依赖显示语言。
- 将矩形右边界改名 `rect_right`，保留左/右键参数；重新通过全部 23 项功能检查。
- 插件管理器使用原生方向键切换标签，产生实际选择通知，不移动用户鼠标；发送操作前等待标签和按钮状态。
- 通过 loopback HTTP 服务提供真实发布 ZIP，实际验证 GUP 下载、哈希、安装、卸载和升级；公网 URL 需发布后单独验证。

## 结果
1.1.1 完成安装、移除及从 1.1.0 升级三项检查；升级清理旧文件并保留 INI，测试进程退出。报告：`build/plugin-admin-20261007-135619/result.json`。
