# 真实宿主启动与隐藏视图

## 独立测试宿主启动失败
最初测试在创建主窗口前退出，Windows 记录 `0xc0000409`。禁用或移走插件 DLL 仍可复现，转储中未加载 folderpad++，由此排除插件初始化。

最终测试复制宿主配套资源及插件目录清单，使用独立配置，移除启动命令中的 `-noUpdater` 参数，并清理子进程继承的 POSIX locale 变量。关键对照是不带 `-noUpdater` 的启动成功；未改动已安装编辑器的设置。

## “其它”多出 new 1
`NPPM_GETNBOPENFILES` 对隐藏第二视图仍返回占位 buffer，直接枚举会把它当作用户文档。

解决：检查 Scintilla 到宿主之间各级窗口的可见样式，跳过隐藏视图。不用整个祖先链的 `IsWindowVisible`，因为宿主整体可能在启动时隐藏。双视图显示时按 buffer ID 去重。

验证：父目录、嵌套目录与其它目录中的三个文档各计数 1；克隆到第二视图不增加条目；真正新建的未保存文档会计入“其它”。
