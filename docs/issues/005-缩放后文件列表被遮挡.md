# 缩放后文件列表被遮挡

## 原因
文件列表数据仍在，但 TabControl 覆盖整个内容区域，与列表是同级窗口；它的 Z 顺序高于列表，缩放重绘时标签背景覆盖列表。

## 修复
布局时将标签控件放到同级窗口底部；控件启用 WS_CLIPSIBLINGS，避免绘制到前景内容上。空列表提示在前景；布局变化后请求面板及子控件重绘。多行标签切换也重新布局，因为选中标签行可能改变页面区域。

## 回归证据
在独立宿主中改变面板窗口宽度并强制重绘，检查条目仍在，且列表内部点命中的子窗口是 ListView 而非 TabControl。旧 DLL 检查失败，新 DLL 在 420、180、560、260 像素宽度下均通过。自动化覆盖分隔条拖动的 WM_SIZE/重绘路径，不操作用户鼠标。
