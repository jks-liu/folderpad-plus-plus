# folderpad++ 1.1.1

Organize already-open Notepad++ documents into folder tabs in a dockable panel. Adding a folder never scans its contents. English and Simplified Chinese are supported.

## Changes
- Add folder now starts in the active file's directory, overriding the file picker's remembered location. Unsaved documents keep the system default location.
- Release ZIP now places `folderpad++.dll` at its root for Notepad++ Plugins Admin installation.

## Installation
Windows x64 only. The initial supported baseline is Notepad++ 8.9.8.1; earlier versions have not been validated. x86 and ARM64 packages are not included.

For manual installation, close Notepad++ after saving your documents, extract `folderpad++.dll` into `<Notepad++>/plugins/folderpad++/`, and restart. Then select **Plugins → folderpad++ → Show / Hide panel**. Remove a folder tab to remove grouping; this does not close or delete files.

The plugin is licensed under GPL-3.0-or-later. The matching source ZIP is provided alongside the binary ZIP. See `SHA256SUMS.txt` for archive hashes.
