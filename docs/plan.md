# 任务与进度

目标：实现 folderpad++ 原生 Notepad++ 插件，在左侧停靠面板以文件夹标签组织已打开文档；不扫描目录；支持中英文。

## 已确定规则
- 文件夹仅保存路径，不枚举目录；列表来自宿主打开的 buffer。
- 按 Windows 路径规则匹配目录边界，嵌套目录优先最长匹配。
- 未归属文件、未保存文档进入“其它”；移除标签不关闭文档。
- 点击文件激活宿主文档；跟随活动文档切换标签；支持双视图。
- 持久化文件夹、语言和面板显示状态；默认语言跟随宿主。

## 安装状态与下一步
- 尝试写入 `C:\Program Files\Notepad++\plugins\folderpad++` 被系统权限拒绝，当前没有安装到用户宿主。
- 用户需在管理员 PowerShell 执行 `./tools/install.ps1`，或将安装包中的 `plugins/folderpad++` 目录复制到 Notepad++ 安装目录。
- 用户正在使用的编辑器没有被关闭；首次安装后自行重启即可加载。更新已有 DLL 时需先保存文档并关闭对应宿主。
- 不再需要编码或扩展测试；若后续修改，先复现具体问题再运行相关检查。

## 验收
- DLL 可被本机 Notepad++ 加载，左侧可添加/移除目录并切换语言。
- 打开/关闭/另存为/激活文档后归属正确；覆盖前缀冲突、嵌套目录、Unicode、双视图。
- 重启后配置恢复；不扫描目录、不修改或关闭用户文档。
